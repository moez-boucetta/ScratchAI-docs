Scratch AI supports a wide range of AI models from leading providers. You choose which model to use in the [Settings panel](/configuration/settings) — each provider requires its own API key. Several providers offer free tiers, so you can start building Scratch projects with AI at no cost.

## Choosing the Right Model

Not all models are equal for every task. Here are some practical recommendations:

- **Just getting started?** Use **Google Gemini 3.7 Flash**. It is fast, free to try via Google AI Studio, and handles most Scratch tasks well.
- **Building a complex project or full game?** Reach for **GPT-5.6**, **Claude Sonnet 5**, or **Gemini 2.5 Pro** — they reason more carefully over longer instructions.
- **On a budget?** **DeepSeek V4 Flash** offers strong performance at very low cost per request.
- **Want to try many models without managing multiple keys?** Use **OpenRouter** — one API key unlocks hundreds of models from different providers.

## Free Options

  The easiest way to start for free is with **Google Gemini**. Visit [aistudio.google.com/apikey](https://aistudio.google.com/apikey) to generate a free API key in under a minute, then open Scratch AI's Settings and select **Gemini 3.7 Flash**. The free tier is generous enough for regular Scratch use with no credit card required.

## Model Performance Tips

Keep these points in mind as you work with Scratch AI:

- **For simple sprite and script tasks** — any fast model works well. Try Gemini 3.7 Flash, Gemini 3.5 Flash Lite, or DeepSeek V4 Flash for quick turnaround.
- **For generating full projects or complex game logic** — use a more capable model such as GPT-5.6, Claude Sonnet 5, or Gemini 2.5 Pro. These handle multi-step instructions and longer context more reliably.
- **If you receive empty or strange responses** — try switching to a different model, or open Settings to confirm your API key is correct and hasn't expired.
- **If you see a 429 rate-limit error** — you have exhausted your free-tier quota for that provider. Wait a minute and try again, upgrade to a paid plan, or switch to a different provider with remaining quota.

<Info>
  Scratch AI detects the correct API endpoint automatically based on the model you select — you never need to enter a URL manually. For OpenRouter, it always routes through `openrouter.ai/api/v1/chat/completions` regardless of which model ID you enter.
</Info>
