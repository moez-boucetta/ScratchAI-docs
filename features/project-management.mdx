Scratch AI can generate a complete Scratch project from a single natural-language description — sprites, scripts, costumes, backdrops, variables, and all. You don't need to build piece by piece; just describe the kind of project you want and Scratch AI assembles a fully playable result in seconds.

## Generating a Full Project

Open the Scratch AI chat panel on any project page and type a single descriptive prompt:

```
create a simple platformer game with a player and three platforms
```
```
build a Pong game with two paddles and a ball
```
```
make an animation of a rocket flying through space with stars
```
```
create a quiz game with 5 questions about animals
```

Scratch AI will:

- **Create sprites** for every character, object, and UI element described
- **Draw costumes** as SVG artwork tailored to each sprite's role
- **Add scripts** covering movement, collisions, scoring, win/lose conditions, and any other logic your description implies
- **Set up variables and lists** needed by the game mechanics (score, lives, timers, question banks, and so on)
- **Run a green-flag test** and report whether the scripts are working before handing control back to you

<Note>
  Complex projects may take a few extra seconds as the AI plans multiple sprites and scripts simultaneously. A *"thinking…"* indicator in the chat lets you know work is in progress.
</Note>

## Renaming Your Project

Give your project a proper title so it's easy to find after you export or publish it:

```
rename the project to My Platformer
```

Scratch AI uses the `setProjectName` action to update the title immediately — you'll see the change reflected in the browser tab and in the Scratch editor header.

## Exporting as .sb3

When you're ready to save or share your project, export it as a standard Scratch file:

```
export the project
```

Scratch AI triggers the `exportProject` action, which downloads a `.sb3` file to your computer. The file is fully compatible with:

- The **Scratch offline editor** (desktop app)
- **scratch.mit.edu** — you can upload it directly to your Scratch account and share it with the community
- Any other tool that opens standard Scratch 3 project files

## Green-Flag Testing

Every time Scratch AI builds or modifies scripts, it automatically runs a green-flag test and reports the result in the chat. You'll see output like:

```
⚑ Flag test on "Player": 2 thread(s) started, position 0,0 → 0,0 — WORKING ✓ (key-controlled)
```

The report shows the thread count, position change, working status, and whether the script is key-controlled. If anything isn't working, Scratch AI will attempt an automatic repair and show you the updated result.

## Iterating on a Project

The initial generation is just a starting point. Keep chatting to refine and extend your project:

```
make the player jump higher
```
```
add more platforms and make them move left and right
```
```
change the background colour to dark blue
```
```
add a sound effect when the player scores a point
```

Each follow-up prompt builds on the current state of your project. Scratch AI reads what's already there and applies only the changes you describe, leaving the rest intact.

When you want to start an entirely different project or give the AI a clean context, click **New chat** in the chat panel to clear the conversation history.

<Tip>
  For complex projects, start with a high-level prompt and then refine step by step. For example, first ask for a basic platformer, then ask to add enemies, then ask to add a score system. Scratch AI handles one coherent set of changes at a time and is more accurate when each prompt has a focused goal.
</Tip>

<Note>
  Projects generated by Scratch AI are fully standard Scratch projects. You can export them and upload to scratch.mit.edu, share them with the community, or continue editing manually in the Scratch editor — no lock-in, no special format.
</Note>
