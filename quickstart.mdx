Once Scratch AI is installed, the only thing standing between you and your first AI-built Scratch project is a model selection and an API key. This guide walks you through the entire setup — from opening the panel for the first time to watching your project come to life — in five minutes or less.

<Info>
  **Prerequisites:**
  - Scratch AI installed in Chrome — see the [Installation guide](/installation) if you haven't done this yet.
  - An API key from one of the supported AI providers. If you want a free option, grab a Google Gemini key from [Google AI Studio](https://aistudio.google.com) at no cost. See [AI Models](/configuration/ai-models) for a full list of providers.
</Info>

## Steps

<Steps>
  <Step title="Open a Scratch project">
    Navigate to [scratch.mit.edu](https://scratch.mit.edu) and open any project in the editor. The URL should look like `scratch.mit.edu/projects/123456789/editor`. You can use an existing project or create a brand-new empty one — Scratch AI works equally well with both. Once the editor loads, click the **Scratch AI** tab in the top toolbar to open the AI chat panel.
  </Step>
  <Step title="Open Settings">
    In the top-right corner of the Scratch AI panel, click the **⚙️ gear icon**. The Settings dialog opens. This is where you connect Scratch AI to your chosen AI model and provide your API key.
  </Step>
  <Step title="Choose a model">
    In the Settings dialog, open the **Model** dropdown and select the AI model you want to use. A few popular choices:

    - **Gemini 1.5 Flash** (Google) — fast, capable, and available on a generous free tier via [Google AI Studio](https://aistudio.google.com)
    - **GPT-4o** (OpenAI) — very strong at following complex multi-step instructions
    - **Claude 3.5 Sonnet** (Anthropic) — excellent at creative and nuanced tasks

    If you're unsure, start with **Gemini 1.5 Flash** — it requires only a free Google account to get an API key and has no upfront cost.
  </Step>
  <Step title="Enter your API key">
    Paste your API key into the **API key** field in the Settings dialog. Your key is saved locally in your browser's storage and is sent directly to the AI provider — it never passes through any Scratch AI server. Click **Save** to confirm. The Settings dialog closes.
  </Step>
  <Step title="Send your first prompt">
    In the chat input at the bottom of the Scratch AI panel, type a plain-language description of what you want to build. For example:

    ```
    add a player controller so the sprite moves with the arrow keys
    ```

    Press **Enter** or click the **→** send button to submit your prompt.
  </Step>
  <Step title="Watch Scratch AI build">
    The panel displays a **"thinking…"** indicator while the AI model processes your request. In a few seconds, Scratch AI carries out the resulting actions directly on your live project — you will see the new sprite appear in the Scratch sprite panel and its scripts added to the code area, all without leaving the chat. The AI also summarises what it did in the chat, so you always know exactly what changed.
  </Step>
  <Step title="Test your project">
    Click the **green flag** above the Scratch stage to run your project. Your sprite should respond to the arrow keys immediately. If something isn't right, describe the fix in the chat — for example, `make the player move faster` or `the sprite is moving in the wrong direction, please fix it` — and Scratch AI will update the scripts for you.
  </Step>
</Steps>

## Example Prompts to Try

<Tip>
  These prompts are great starting points — copy them directly into the chat or use them as inspiration for your own ideas:

  - `add a player controller so the sprite moves with the arrow keys`
  - `create a simple platformer game with a player and platforms`
  - `add a score variable that increases when the player touches a star`
  - `draw a spaceship costume for Sprite1`
  - `make the player jump when I press the space bar`
  - `add a backdrop of a city skyline and play a sound effect when the game starts`
  - `create a quiz game with three questions and a final score screen`
</Tip>

You can keep the conversation going just like a regular chat. Each follow-up prompt builds on the current state of your project, so you can iterate quickly — add features, fix bugs, and tweak visuals all in plain language. Use the **Undo** button at any time to roll back the last AI action, and the **New Chat** button to start a fresh conversation when you move on to a different task.
